Dr. Maker Project

DrWalls

Wi-Fi CSI Motion Detection
Turn an ESP32 into a motion sensor using the Wi-Fi signals already traveling through your room.
No camera. No PIR sensor. No additional sensing hardware.

Install DrWalls

Connect your ESP32 with USB and install the firmware directly from your browser.

Requires a compatible ESP32 and a browser that supports Web Serial, such as Google Chrome or Microsoft Edge on desktop.

After Installation

1
Connect to DrWalls-Setup After installation, the ESP32 creates its own temporary Wi-Fi network.
2
Configure Wi-Fi The setup page should open automatically. Select your Wi-Fi network and enter its password.
3
Open the CSI Radar Once connected, open http://drwalls.local from a device on the same network.
4
Move! DrWalls analyzes changes in Wi-Fi CSI data and displays whether movement is detected.
DrWalls is an experimental maker project. Detection performance can vary depending on ESP32 placement, router position, room layout, interference, and the surrounding environment.
